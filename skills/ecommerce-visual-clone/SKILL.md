# Ecommerce Visual Clone Skill

## Purpose
A Codex Skill for recreating high-conversion e-commerce visuals from reference images.

## Modes

### precision_clone
- Preserve product identity
- Preserve phone case shape, camera module, material and artwork
- Remove unwanted accessories (lanyards, charms, decorations)
- Rebuild lighting, composition and scene

### style_rebuild
- Extract visual DNA from reference images
- Apply style language to user's own product
- Generate multiple hero image variations

## Product Rules
- Phone case is the primary object
- Never add a strap unless the user product contains one
- Never alter camera cutout structure
- Never replace the user's design artwork

## Workflow
1. Analyze reference image
2. Extract Visual DNA
3. Create generation brief
4. Generate variants
5. Run QA check

## Target Platforms
- Taobao main image
- Product detail pages
- Xiaohongshu creatives
